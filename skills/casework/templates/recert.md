# SNAP recertification payload

Assemble for submission (hand to formfiller):
- applicant_id, case_id
- household_size
- monthly_income (sum of verified income)
- work_hours_per_week + verification status
- exemption_claimed (if any) + basis
- documents_attached (notice ids / doc types)
- caseworker_attestation: true (set only after caseworker review)
